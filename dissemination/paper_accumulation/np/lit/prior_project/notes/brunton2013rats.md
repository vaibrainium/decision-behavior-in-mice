# brunton2013rats

**Citation:** Brunton BW, Botvinick MM, Brody CD. 2013. Rats and humans can optimally accumulate evidence for decision-making. *Science* 340:95–98. DOI: 10.1126/science.1233912. PMID: 23559254.

**Access:** abstract only, PubMed. **Question:** Can trial-specific evidence timing separate noise in new evidence from noise in accumulator memory? **Species/task:** rats and humans; auditory evidence delivered in randomly timed pulses. **Method:** generative accumulation models using each trial's pulse times.

**Key findings:** The abstract reports little/no measurable memory noise and identifies incoming-evidence noise as the main variability source in the tested tasks.

**Relevance:** precedent for using precisely timed evidence events and joint modelling to infer accumulator properties. **Limitation:** auditory click pulses with known event times differ fundamentally from reconstructed random-dot motion energy.
