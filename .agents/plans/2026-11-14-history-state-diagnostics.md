## Goal
Implement the author-approved literature follow-up using existing data: audit chronology, quantify history-conditioned choice bias/RT, test residual serial structure, and use those findings to select a compact model comparison or a bounded gain feasibility test. Deliver reproducible per-mouse results and figures, not an attention label inferred from model fit alone.

## Context
Substantial static history effects are already documented. The current condition-pooled likelihood does not validate trial ordering. The independent postdecision-delay pilot failed to explain the pulse/RT tradeoff. See dissemination/attention_decision_review_2026-11-14/NEXT_ANALYSES.md.

## Assumptions
- Preserve the responded-only DDM population for main comparisons; reconstruct its history from the full recorded within-session chronology, including gaps/correction/late trials. Do not modify raw or previous derived inputs/results.
- Current RT-conditioned history effects are descriptive, not a causal estimate of bias evolution. Compare mechanism-specific predictions through the same selection before choosing a DDM extension.
- Evaluate biological claims across mice, with block-aware within-mouse uncertainty. Simulation seeds, trials and sessions are not independent animals.
- Start with existing dependencies/local computation. No installations, cluster submissions, external data transfer or changes to historical protocols.

## Out of scope
New experiments, declaring attention/arousal from behavior alone, unconstrained combinations of many new mechanisms, or claiming unique integration memory from response-conditioned curves. Any later full-cohort fit or recovery expansion depends on an informative pilot.
